สรุปการแก้ไขบักในโปรเจกต์ (3_WITHOUT_MCP/app.py)
==================================================

1. ฟังก์ชัน divide(a, b):
   - ปัญหาเดิม: ไม่มีเงื่อนไขตรวจสอบการหารด้วยศูนย์ (Division by zero) ทำให้เกิด ZeroDivisionError เมื่อ b = 0
   - การแก้ไข: เพิ่มการตรวจสอบ `if b == 0: return 0` เพื่อป้องกันข้อผิดพลาดและจัดการการหารด้วยศูนย์อย่างปลอดภัย

2. ฟังก์ชัน calculate_discount(price, discount_percent):
   - ปัญหาเดิม: คำนวณเปอร์เซ็นต์ส่วนลดผิดพลาด โดยนำ discount_percent ไปลบกับ 1 โดยตรง (1 - discount_percent) ทำให้ค่าส่วนลดผิดพลาดอย่างรุนแรง
   - การแก้ไข: ปรับปรุงสูตรเป็น `price * (1 - discount_percent / 100)` เพื่อหารด้วย 100 ให้เป็นเปอร์เซ็นต์ที่ถูกต้อง

3. ฟังก์ชัน format_user_name(first, last):
   - ปัญหาเดิม: ไม่มีการจัดการกรณี first หรือ last เป็น None ทำให้เกิด TypeError เมื่อนำมาเชื่อมสตริงด้วยเครื่องหมาย +
   - การแก้ไข: ปรับปรุงให้กรองเอาเฉพาะค่าที่ไม่ใช่ None หรือค่าว่างก่อนนำมาประกอบด้วย `parts = [p for p in (first, last) if p]` และส่งคืนด้วย `" ".join(parts)`
