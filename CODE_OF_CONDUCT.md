# Contributor Covenant Code of Conduct (short)

## Our pledge

Be respectful. No harassment, hate, or personal attacks in issues, PRs, or discussions.

## Scope

Project spaces (GitHub issues/PRs/discussions) and official project channels.

## Enforcement

Report abuse via [GitHub Security Advisories](https://github.com/taurus42119-stack/godkiller-mcp/security/advisories)
or the maintainer contact in `SECURITY.md`. Maintainers may warn, hide, or ban.
