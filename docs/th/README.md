# Thai locale documents (optional)

Not the PyPI / wheel default. English ship surface lives in:

- `src/godkiller_mcp/bundled_agents/`
- package-root `.agents/` (English)

Set `GODKILLER_LOCALE=th` if you want Thai UI-plan intent aliases at runtime.
Point `GODKILLER_AGENTS_MD` at `docs/th/agents/AGENTS.md` when you want the Thai constitution on a host.
